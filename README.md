# Simple-ProcessExplorer

A lightweight, powerful, and completely terminal-based Task Manager for Windows, written in C++.

This tool provides a real-time view of all running processes on your system directly from the command line. Unlike standard console applications that suffer from screen flickering when updating data, this project uses advanced cursor management and ANSI escape codes to deliver a smooth, seamless, and dynamic user interface without relying on any heavy GUI frameworks.

Key Features:

Live Monitoring & Sorting: Automatically tracks active processes and dynamically sorts them by memory (RAM) usage, so you can easily spot resource-heavy programs.

Full Process Control: Quickly find specific processes by name, and easily suspend (pause), resume, or kill them straight from your keyboard.

Deep Properties Inspection: Dive into any specific process to uncover detailed information, including its exact file path, creation time, active threads (with their priorities), and a full list of loaded modules (DLLs).
